# Space shooter
A simple space shooter game built with Python and Pygame.
The player controls a spaceship, shoots incoming enemies, earns points, and tries to survive as long as possible.

## Features

- Player-controlled spaceship
- Keyboard movement
- Shooting system
- Enemy spawning
- Collision detection
- Score tracking
- Background music
- Shooting and hit sound effects
- Game-over state
- Restart functionality

## Technologies Used

- Python
- Pygame

## Controls
Use the keyboard to control the spaceship and shoot enemies.
- Arrow keys: move the spaceship
- Spacebar: shoot

## Gameplay

Enemies appear on the screen and move toward the player.
The player must move the spaceship and shoot enemies before they reach the bottom of the screen.
Bullets disappear after leaving the visible game area or after hitting an enemy.
The score increases when an enemy is successfully destroyed.
If the game ends, the player can restart and try again.
